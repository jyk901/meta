Python 기초

1input()이 돌려주는 자료형str (문자열)
2키-값 쌍으로 저장하는 자료형dict
3함수가 결과를 돌려주는 키워드return
4① 횟수 정해짐·목록 순회 ② 조건이 참인 동안 반복① for ② while
5① if 다음 추가 조건 ② 모두 거짓일 때① elif ② else
6참/거짓 · 순서 있는 목록 · 정수bool · list · int

💡 input()은 항상 str → 숫자는 int()로 변환 → 실패하면 ValueError. 자료형 5종: int·str·bool·list·dict

클래스·객체

7객체 생성 시 자동 호출되는 메서드__init__ (생성자)
8객체 자기 자신을 가리키는 이름self
9① 객체가 가진 데이터 ② 객체의 행동(함수)① 속성(attribute) ② 메서드(method)
10① 설계도 ② 설계도로 만든 실물① 클래스 ② 객체(인스턴스)
11클래스를 정의하는 키워드class
12q의 choices 속성을 읽는 코드q.choices

💡 클래스=붕어빵 틀(설계도), 객체=붕어빵. 점(.)은 "~의": q.choices = q의 선택지

파일·JSON·예외

15int("abc") 때 발생하는 예외ValueError

18Ctrl+C를 눌렀을 때 예외 (입력 종료는?)KeyboardInterrupt (EOFError)

💡 프로그램을 꺼도 데이터가 남는 것 = 데이터 영속성. 파일이 없거나 깨져도 안 멈추게 = try/except

Git ① 기록 흐름

19변경 파일을 스테이징에 올리는 명령git add
20스테이징한 변경을 로컬에 기록git commit
21로컬 커밋을 원격(GitHub)에 올림git push
22현재 폴더를 새 Git 저장소로 시작git init
23추적하지 않을 파일을 적는 파일.gitignore
24커밋 접두어 ① 새 기능 ② 오류 수정 ③ 문서① Feat ② Fix ③ Docs (Refactor=구조 정리)

💡 흐름: 작업 폴더 → add(스테이징) → commit(로컬 기록) → push(원격 업로드)

Git ② 브랜치·원격

25브랜치 이동 (-b 붙이면 생성+이동)git checkout
26작업 브랜치를 합치는 명령git merge
27① 원격을 처음 복제 ② 변경사항 가져오기① git clone ② git pull
28브랜치 목록 보기git branch
29복제 실습: ① 올리기 ② 원래 폴더에서 가져오기① git push ② git pull
30merge 실행 전 이동해야 하는 브랜치main (받는 쪽)

💡 clone=처음 복제 1회, pull=변경 가져오기. 병합은 받는 쪽(main)으로 이동해서 merge
