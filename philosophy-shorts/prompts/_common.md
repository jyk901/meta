# 공통 규칙 (모든 에이전트가 따른다)

시리즈: **1분 철학** — "어려운 철학 말고, 쓰는 철학"
약속: 영상 1편 = 철학자 1명 = 개념 1개 = 오늘 할 행동 1개

## 절대 규칙
1. **One idea**: 개념이 둘 나오면 실패. 하나는 다음 편으로.
2. **원전 우선**: 출처(저작·장·절)가 확인된 인용만 쓴다. 인터넷 유행 명언은 기본 반려.
3. **일상 연결 필수**: "오늘 할 수 있는 행동 1개"가 없으면 완성이 아니다.
4. **질문으로 끝**: 결론을 닫지 않는다. 되묻는 질문이 댓글을 만든다.
5. **쉬운 말**: 중학생이 들어도 되는 문장. 전문 용어는 편당 1개, 반드시 풀어쓴다.
6. **톤**: 차분·단정·존댓말("~합니다"). 과장·클릭베이트·느낌표 남발 금지.

## 60초 구조 (고정)
| 구간 | 초 | 역할 | 규칙 |
|---|---|---|---|
| 1. 훅 | 0~3 | 시청자 상황을 한 문장으로 찌른다 | 철학자 이름 금지 |
| 2. 문제 | 3~12 | 구체적 일상 장면 2개 | "우리는 ~합니다" 공감 |
| 3. 사상 | 12~38 | 철학자 등장 + 핵심 개념 1개 | 원전 근거 1개 이상, 용어 1개 |
| 4. 적용 | 38~52 | 오늘 할 행동 1개 | 명령문. "하나만 해보세요" |
| 5. 마무리 | 52~59 | 되묻는 질문 + 시그니처 | 끝 문장은 "1분 철학이었습니다." |

## 파일 규약
- 에피소드 폴더: `episodes/EPxxx/` (예: EP001)
- 상태 파일: `episodes/EPxxx/episode.json` — 단계 완료 시 `python3 tools/stage.py EPxxx <stage> done artifact=<파일명> [key=value ...]` 로 갱신한다.
- 모든 산출물은 UTF-8 한국어. 파일 밖(채팅)에 내용을 길게 복사하지 말고 파일 경로와 요약만 보고한다.
