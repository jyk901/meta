# 1분 철학 쇼츠 — 기획안 (에이전트 제작 파이프라인)

작성일: 2026-11-24

---

## 1. 한 줄 콘셉트

> **"2천 년 된 생각으로 오늘 아침의 고민을 푼다."**
> 철학자 한 명의 핵심 아이디어 하나를, 시청자의 일상 문제에 꽂아 60초 안에 끝낸다.

- 시리즈명(가안): **1분 철학**
- 슬로건: *"어려운 철학 말고, 쓰는 철학"*
- 핵심 약속: 영상 1편 = 아이디어 1개 = 오늘 바로 써먹는 행동 1개

## 2. 타깃 · 채널 · 톤

| 항목 | 결정 |
|---|---|
| 1차 타깃 | 20~30대 직장인·대학생. 자기계발 콘텐츠는 보지만 철학책은 안 읽는 층 |
| 2차 타깃 | 40대 이상 "교양" 수요층 (유튜브 쇼츠 체류시간 높음) |
| 채널 | YouTube Shorts 메인 → 같은 파일로 Instagram Reels, TikTok 동시 배포 |
| 톤 | 차분하고 단정. 과장·클릭베이트 금지. 존댓말. "~합니다" 체 |
| 화자 | 보이지 않는 내레이터 (AI 보이스). 캐릭터 아바타는 2차 실험 항목 |
| 비주얼 | 어두운 배경 + 키네틱 타이포그래피 + 에피소드당 6~8장의 생성 이미지 (일관된 화풍) |

## 3. 영상 규격 · 60초 타임라인 템플릿

- 1080×1920 (9:16), 30fps, 55~59초 (60초 초과 금지)
- 한국어 내레이션 분량: **270~320자** (TTS 속도 기준 약 55초)
- 자막: 항상 번인(burn-in). 음소거 시청 전제
- 구조는 **고정**. 에이전트가 이 틀 안에서만 쓰게 해서 품질 편차를 줄인다.

| 구간 | 시간 | 역할 | 규칙 |
|---|---|---|---|
| ① 훅 | 0~3초 | 시청자의 상황을 한 문장으로 찌른다 | 철학자 이름 금지. 질문 또는 단정문 |
| ② 문제 | 3~12초 | 구체적 일상 장면 2개 | "우리는 ~합니다" 형태로 공감 |
| ③ 사상 | 12~38초 | 철학자 등장 + 핵심 개념 1개 | 원전 근거 1개 이상. 용어는 한 개만 |
| ④ 적용 | 38~52초 | 오늘 할 수 있는 행동 1개 | 명령문. "하나만 해보세요" |
| ⑤ 마무리 | 52~59초 | 되묻는 질문 + 시그니처 | 댓글 유도 질문 → "1분 철학이었습니다" |

## 4. 에피소드 설계 원칙 (에이전트 시스템 프롬프트에 그대로 들어감)

1. **One idea**: 개념 두 개가 나오면 탈락. 둘 중 하나는 다음 편으로.
2. **원전 우선**: 인용은 출처(저작·장·절)가 확인된 것만. 인터넷 유행 "명언"은 검수 에이전트가 기본 반려.
3. **일상 연결 필수**: ④ 적용 구간이 없으면 완성으로 치지 않는다.
4. **질문으로 끝**: 결론을 닫지 않는다. 댓글은 쇼츠 알고리즘의 핵심 신호.
5. **쉬운 말**: 중학생이 들어도 되는 문장. 전문 용어는 편당 1개, 반드시 풀어쓴다.
6. **반대 입장 한 줄**: 가능하면 ③ 끝에 "물론 ~라는 반론도 있습니다" 한 문장. 균형이 신뢰를 만든다.

## 5. 에이전트 파이프라인

```
[주제 뱅크] ──▶ ① 리서처 ──▶ ② 작가 ──▶ ③ 철학 검수 ──┐
                                  ▲                     │ 반려 시 최대 2회 루프
                                  └─────────────────────┘
                                                        ▼
                               [사람 체크포인트 A: 대본 승인]
                                                        ▼
                     ④ 비주얼 디렉터 ──▶ ⑤ 자산 생성 ──▶ ⑥ 편집·합성
                                                        ▼
                               [사람 체크포인트 B: 최종 영상 승인]
                                                        ▼
                                ⑦ 퍼블리셔 ──▶ (48h 후) ⑧ 애널리스트 ──▶ 주제 뱅크 갱신
                       ⓞ 오케스트레이터가 전체 상태(episode.json)를 관리
```

### 에이전트 역할표

| # | 에이전트 | 입력 → 출력 | 권장 모델 | 도구 |
|---|---|---|---|---|
| ⓞ | 오케스트레이터 | 주간 제작 요청 → 에피소드별 상태 머신 진행, 재시도, 사람 호출 | `claude-opus-5-5` | 파일 시스템, 서브에이전트 호출 |
| ① | 리서처 | 주제 1줄 → `brief.md` (핵심 개념, 원전 인용 2~3개 + 출처, 흔한 오해, 일상 연결 후보 3개) | `claude-opus-5-5` | 웹 검색·페치 |
| ② | 작가 | brief → `script.md` (5구간 타임코드, 270~320자, 제목 후보 3개) | `claude-opus-5-5` | 없음 (순수 생성) |
| ③ | 철학 검수 | script + brief → `review.json` (통과/반려, 오귀속·과단순화·사실오류 지적, 수정 지시) | `claude-opus-5-5`, effort `high` | 웹 검색 (인용 재확인) |
| ④ | 비주얼 디렉터 | script → `storyboard.json` (컷 6~8개: 시작·끝 타임코드, 이미지 프롬프트, 자막 강조어, 전환) | `claude-sonnet-5-5` | 없음 |
| ⑤ | 자산 생성 | storyboard → 이미지 PNG, 내레이션 WAV, 자막 SRT | 코드 실행 (LLM 호출 최소) | 이미지 생성 API, 한국어 TTS API |
| ⑥ | 편집·합성 | 자산 → `final.mp4` | 코드 실행 | ffmpeg 또는 Remotion |
| ⑦ | 퍼블리셔 | script + mp4 → 제목·설명·해시태그·썸네일 문구, 업로드 예약 | `claude-haiku-5-5` | YouTube Data API |
| ⑧ | 애널리스트 | 48시간 지표 → `metrics.json` + 주제 뱅크 가중치 조정 제안 | `claude-haiku-5-5` | YouTube Analytics API |

> 모델 선택 이유: 대본·검수는 품질이 곧 채널 신뢰라 Opus 5.5. 메타데이터·지표 정리처럼 정형 작업은 Haiku 5.5로 비용을 줄인다. 모든 호출에 `fallbacks: "default"`(베타 `server-side-fallback-2026-07-01`)를 켜서 안전 분류기 거절 시 자동 대체되게 한다.

### 사람 체크포인트 (딱 2곳)

- **A. 대본 승인**: 검수 통과본을 사람이 읽고 OK/수정. 1편당 1~2분.
- **B. 업로드 전 미리보기**: 최종 mp4 재생 후 OK. 초기 20편은 반드시, 이후 샘플링.

그 외 모든 단계는 에이전트가 자율로 처리한다. 반려 루프가 2회를 넘으면 오케스트레이터가 주제를 보류하고 다음 주제로 넘어간다.

## 6. 기술 스택 선택지

| 방식 | 장점 | 단점 | 추천 시점 |
|---|---|---|---|
| **A. Claude Code + 서브에이전트** (`.claude/agents/*.md`에 역할별 정의) | 오늘 바로 시작. 저장소가 곧 작업장. 사람 체크포인트가 자연스러움 | 사람이 세션을 열어야 돌아감. 완전 자동 스케줄 불가 | **0~20편 (추천 시작점)** |
| **B. Managed Agents + 예약 배포** | Anthropic이 루프·샌드박스 호스팅. 매일 새벽 자동 생산. 대본 승인은 `tool_confirmation`으로 사람 호출 | 베타. 세션 런타임 과금 추가 | 20편 이후 주 5편 자동화 |
| **C. Claude Agent SDK** 직접 호스팅 | 완전한 제어. 자체 서버·크론 | 하네스·배포를 내가 운영 | 자체 인프라가 이미 있을 때 |

**권장 경로**: A로 포맷과 프롬프트를 20편 안에서 검증 → 검증된 프롬프트를 그대로 B의 에이전트 설정으로 옮겨 자동화.

### 자산 생성 도구 후보

| 자산 | 1순위 | 대안 | 비고 |
|---|---|---|---|
| 이미지 | Z-Image Turbo (HF Spaces) | Higgsfield, Canva 이미지 생성 | 화풍 프롬프트를 시리즈 공통 접두어로 고정 |
| 한국어 TTS | ElevenLabs (한국어 다국어 모델) | Typecast, Supertone | 보이스 1개로 고정. 속도 1.05배 |
| 합성 | ffmpeg (자막 번인 + Ken Burns 줌) | Remotion (React 기반, 모션 타이포 강함) | ffmpeg로 시작, 모션 품질 필요 시 Remotion |
| BGM | 라이선스 라이브러리 (Epidemic, Artlist) | YouTube 오디오 라이브러리 | 저작권 클레임 방지 |

## 7. 제작 워크플로우 (주간 배치)

| 요일 | 작업 | 담당 |
|---|---|---|
| 월 오전 | 이번 주 5개 주제 확정 (주제 뱅크 + 애널리스트 제안) | 사람 10분 |
| 월 | ①→③ 리서치·대본·검수 5편 일괄 | 에이전트 |

| 화~수 | ④→⑥ 스토리보드·자산·렌더 5편 | 에이전트 |
| 목 오전 | 체크포인트 B: 영상 5편 확인 | 사람 15분 |
| 목 | ⑦ 월~금 예약 업로드 (매일 1편, 업로드 시각 고정) | 에이전트 |

→ 사람 투입 **주 40분**으로 주 5편.

## 8. 품질 루브릭 (검수 에이전트 평가 기준 = 사람 승인 기준)

각 5점 만점, 합계 20점 이상 통과. 항목 중 하나라도 2점 이하면 반려.

| 기준 | 5점 | 1점 |
|---|---|---|
| 훅 | 3초 안에 "내 얘기"라고 느낌. 철학자 이름 없음 | 철학자 소개로 시작 |
| 정확성 | 인용·귀속이 원전과 일치, 개념 왜곡 없음 | 출처 불명 명언, 오귀속 |
| 단일성 | 개념 1개, 용어 1개 | 개념 2개 이상 |
| 적용 | 오늘 할 수 있는 구체 행동 1개 | "생각해보세요" 수준의 추상 |
| 마무리 | 되묻는 질문이 ①의 상황과 연결 | 질문 없음 또는 무관 |

## 10. 샘플 대본 — EP001 「남의 평가가 신경 쓰일 때」

철학자: 에픽테토스 / 개념: 통제의 이분법 / 출처: 『엥케이리디온』 1장
본문 약 300자.

| 구간 | 시간 | 내레이션 | 화면 |
|---|---|---|---|
| ① 훅 | 0~3 | 남이 나를 어떻게 생각하는지, 2천 년 전에 이미 답이 나왔습니다. | 검은 화면, 흰 텍스트 "2천 년 전" |
| ② 문제 | 3~12 | 메시지를 읽고 답이 없을 때. 발표가 끝났는데 반응이 미지근할 때. 우리는 하루의 절반을 남의 머릿속을 추측하며 씁니다. | 읽음 표시된 채팅창 / 조용한 회의실 |
| ③ 사상 | 12~38 | 노예 출신 철학자 에픽테토스는 세상을 딱 두 칸으로 나눴습니다. 내 뜻대로 되는 것, 그리고 안 되는 것. 내 판단, 내 말, 내 행동은 첫째 칸. 남의 평가, 날씨, 결과는 둘째 칸. 그는 말했습니다. 괴로움은 둘째 칸의 것을 첫째 칸처럼 붙들 때 온다고. | 두 칸으로 나뉜 화면. 단어들이 좌우로 분류됨 |
| ④ 적용 | 38~52 | 오늘 하나만 해보세요. 걱정이 올라오면 물어보는 겁니다. "이게 내 칸인가?" 아니라면 손을 놓고, 맞다면 그것만 하면 됩니다. | 손이 물건을 내려놓는 이미지, 자막 강조 "이게 내 칸인가?" |
| ⑤ 마무리 | 52~59 | 당신이 지금 붙들고 있는 건 어느 칸인가요? 댓글로 남겨주세요. 1분 철학이었습니다. | 질문 텍스트 + 시리즈 로고 |

- 제목 후보: "남의 평가에 흔들리는 이유, 2천 년 전 노예가 답했다" / "걱정의 90%를 버리는 질문 하나" / "에픽테토스: 이게 내 칸인가?"
- 검수 포인트: "노예 출신"은 사실(히에라폴리스 출신, 에파프로디토스의 노예). 『엥케이리디온』 1장의 "우리에게 달린 것 / 달리지 않은 것" 구분이 직접 근거.
